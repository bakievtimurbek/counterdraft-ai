# CounterDraft AI — Интеллектуальный помощник для драфтов и аналитики Dota 2

**CounterDraft AI** — это профессиональная аналитическая веб-платформа для Dota 2, вдохновленная эстетикой Dotabuff и соревновательной сценой. Платформа объединяет статистику OpenDota, гибкую математическую систему позиций 1–5, 5-факторную оценку драфта, тепловые карты карты и персонального тренера (Personal Improvement Coach).

---

## 🌟 Ключевые возможности

### 1. Draft Analyzer (Анализ драфта)
- **Сетка 5v5** с портретами героев, английскими названиями и разделением по позициям:
  - Position 1 — Carry
  - Position 2 — Mid
  - Position 3 — Offlane
  - Position 4 — Soft Support
  - Position 5 — Hard Support
- **Manual Mode**: ручное фиксирование позиций 1–5.
- **Smart Mode (Flex Picks)**: расчет оптимального распределения ролей методом перебора всех 120 перестановок с учетом пригодности героев и связок линий (Safe Duo, Offlane Duo). Отображение Top 3 вариантов с процентной вероятностью и пояснениями.
- **Ranked Draft vs Captain's Mode**:
  - В соревновательном режиме реализована официальная последовательность из 24 шагов (14 банов и 10 пиков в 3 фазах), очередь ходов Radiant/Dire и отмена шага.
- **5-факторная оценка следующего пика (Next Pick Advisor)**:
  - Контрпик — 30%
  - Матчап на линии — 25%
  - Синергия — 20%
  - Простота исполнения — 15%
  - Масштабирование в лейт — 10%
  - Настраиваемые ползунки весов и пресеты для пабликов и турниров.
- **Полный структурированный отчет драфта**:
  - Винрейт Radiant vs Dire, уверенность модели.
  - 9 шкал сравнения: Контроль (CC), Инициация, Мобильность, Физ./Маг. защита, Анти-иллюзии, Пуш, Рошан, Лейтгейм.
  - Определение уязвимостей и сильных сторон.
  - Анализ Win Condition через Gemini API или встроенный экспертный движок.

### 2. Lane Matchups (Анализ линий)
- Динамический расчет 3 линий:
  - Safe Lane: Radiant (Pos 1 + Pos 5) vs Dire (Pos 3 + Pos 4)
  - Mid Lane: Radiant Pos 2 vs Dire Pos 2
  - Offlane: Radiant (Pos 3 + Pos 4) vs Dire (Pos 1 + Pos 5)
- Оценка килл-потенциала, сустейна, сложности добивания крипов и уязвимости к ганкам.
- Адаптивные рекомендации стартового закупа (Magic Stick против спамеров, Salve от берст-урона, Blood Grenade).
- Мгновенный перерасчет при смене ролей или героев.

### 3. Builds (Система сборок предметов)
- Сборки по стадиям: Starting Items, Early Game, Core Items, Situational Items, Late Game.
- **Динамический учет врагов**:
  - Против Alchemist / Necrophos / Pudge -> Spirit Vessel / Eye of Skadi.
  - Против Phantom Assassin / Windranger -> Monkey King Bar (MKB).
  - Против Bristleback / Spectre / Timbersaw -> Silver Edge (Break).
  - Против точечных ультимейтов (Doom, Duel) -> Linken's Sphere / Lotus Orb.
  - Против магии -> Pipe of Insight / BKB.
- Пояснение стоимости, таймингов и игровой проблемы, которую решает предмет.

### 4. Map Analytics (Тепловые карты и обзор)
- Интерактивная карта Dota 2 с реальными координатами из парсинга реплеев матчей OpenDota.
- 5 переключаемых слоев: Перемещения, Фарм, Тимфайты, Смерти, Варды (Observer & Sentry).
- 4 временных фильтра: 0–10 мин, 10–20 мин, 20–30 мин, 30+ мин.
- Фильтры по сторонам (Radiant / Dire).

### 5. Personal Improvement Coach (Персональный тренер)
- 7 ключевых направлений развития:
  1. Farming (CS/мин, лесной треугольник, тайминги стаков)
  2. Positioning (дистанция в драке, сброс фокуса)
  3. Laning (крип-агр, перетягивание волны, блокировка кемпов)
  4. Map Awareness (руны мудрости, смок-ганки, контроль миникарты)
  5. Teamfight Decisions (приоритет фокуса, байбеки)
  6. Itemization (контр-сборки и тайминги артефактов)
  7. Death Analysis (исключение смертей без вижна)
- Справочник чемпионов The International с подтвержденными матчами и решениями:
  - Pos 1: Yatoro, Satanic, Ame, Watson.
  - Pos 2: Nisha, Malr1ne, Quinn.
  - Pos 3: Collapse, 33, ATF.
  - Pos 4: Cr1t-, XinQ, tOfu.
  - Pos 5: Miposhka, Seleri, Insania.
- Конкретные тренировочные упражнения с измеримыми бенчмарками.
- Генератор персонального плана на неделю с сохранением в браузере.

### 6. Counter Picks & Hero Database
- Каталог 127 героев с фильтрами по атрибутам, ролям и базовым статам.
- Страница контрпиков с Top 5 лучших и худших матчапов и предметами-контрами.

### 7. Match Analysis & Data Status
- Загрузка любого реального матча по OpenDota Match ID.
- Панель мониторинга здоровья API (OpenDota, Gemini AI, Valve CDN, локальный кэш).

## 🛠️ Запуск на Windows

### Предварительные требования
- Windows 10 / 11
- Установлен Node.js v18+ (рекомендуется v24 LTS)
- PowerShell или Командная строка (CMD)

### Установка зависимостей
Откройте PowerShell в папке проекта:
```powershell
cd C:\Users\faruh\.gemini\antigravity\scratch\counterdraft-ai
npm install
```

### Настройка переменных окружения
Скопируйте пример файла конфигурации:
```powershell
Copy-Item .env.example .env
```
При необходимости укажите ваши ключи в `.env`:
- `GEMINI_API_KEY`: API ключ Google Gemini (если не указан, автоматически работает встроенный экспертный статистический движок).
- `OPENDOTA_API_KEY`: API ключ OpenDota (опционально для увеличения лимитов).

### Запуск тестов
Для запуска автоматических тестов алгоритмов Smart Mode, 5-факторного скоринга, Captain's Mode и сборок:
```powershell
npm test
```

### Запуск в режиме разработки
```powershell
npm run dev
```
Откройте в браузере: **http://localhost:3000**

### Сборка и запуск в Production режиме
```powershell
npm run build
npm start
```
